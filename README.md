# 简护 | Simcare

给家人的健康记录本。一个家庭共用一个实例，最多 10 位成员，可记录血压、心率、血氧、体温和用药计划，查看趋势，并在断网时继续记录。

## 在 Cloudflare 安装

目标流程无需本地命令行：

1. 在 Cloudflare **Workers 和 Pages → 创建应用程序** 中连接本 GitHub 仓库，选择 `main` 分支并填写项目名。仓库根目录就是应用目录，无需再填写 `app/`。
2. 保留控制台默认构建、部署命令。项目安装脚本负责构建应用、创建与项目同名的 D1、绑定 `DB` 并执行数据库迁移。
3. 在 Worker **设置 → 变量和机密** 中添加名为 **`init_key`** 的普通变量，填写自己保存的随机字符串并保存。
4. 打开应用，填写手机号、昵称、登录密码和该初始化密钥，建立家庭。首个用户同时是系统管理员和家庭管理员。
5. 如需自定义域，在 Worker 中添加自定义域，待其生效即可访问，不需要填写域名变量或白名单。

**当前验收状态：本地构建、模拟部署流程及浏览器业务测试已完成；Cloudflare 控制台默认命令安装和真实手机验收尚未完成。** 不能将这份目标流程视为已验证的一键安装承诺。Cloudflare 官方列出的默认 Builds 令牌权限未包含 D1 编辑权限；自动建库和迁移是否能在默认配置下执行尚待实测。若 Builds 未提供所需凭据或权限，安装会明确停止，不会要求把 API token 填入应用变量。

`init_key` 同时用于系统管理员应急重设密码，不用于日常登录。无需配置短信服务、Passkey 或 `RP_ID`。兼容旧版大写 `INIT_KEY`；两者同时配置时必须相同。

## 家人如何使用

- 所有人共用手机号和密码登录。密码为 8～64 个字符，不强制大小写、数字和符号混用，支持粘贴和密码管理器。
- 管理员在“我的 → 家庭成员”生成邀请，将链接或二维码交给家人。系统管理员可以选择家庭管理员或普通成员；家庭管理员只能邀请普通成员。
- 家人填写手机号、昵称、密码和设备名称，管理员在“我的 → 加入申请”批准一次。家庭管理员的加入申请由系统管理员批准。以后换设备直接使用手机号和密码登录。
- 手机号仅为家庭内部账号，不发送短信、不验证真实归属，支持大陆 11 位手机号和 +86 前缀。
- 设备默认保持登录 180 天，联网时每天最多续期一次。在“我的 → 已登录设备”可以移除设备。

## 设置和找回密码

在“我的 → 登录密码”设置或修改密码。旧版本升级后保留有效登录；尚未设置密码的成员在此补设密码。

忘记密码时，请家庭管理员在家庭成员页面选择“帮助设置密码”，生成一次性设置链接；家庭管理员自己的链接只能由系统管理员生成。链接 30 分钟有效，新链接会使旧链接失效，家人打开后自己设置密码。不要将链接转发给其他人。密码成功修改或重设后，其他设备需要重新登录，健康记录保留。

系统管理员忘记密码时，在登录页选择“忘记密码”，使用自己的手机号和当前 init_key 设置新密码。无需其他人批准，也不会建立第二个家庭；请妥善保存 init_key。

## 安装到手机桌面

用手机浏览器打开应用，在浏览器菜单中选择“安装应用”或“添加到主屏幕”（具体名称因浏览器而异）。应用完整名称为“简护 | Simcare”，桌面短名称为“简护”。

## 健康与用药

记录支持修正、软删除和历史保留。家庭管理员可查看和照护所有成员；普通成员之间可授予“无权限”“查看”“照护”。家庭用药清单对成员可见。

“今日用药”表示计划，不表示已经服用。应用不提供服药打卡、提醒、医疗诊断或用药建议。时间统一为北京时间。

## 离线与备份

首次登录、加入批准、密码管理、家庭管理和备份恢复需要网络。已经登录并缓存的数据可离线查看，记录在恢复网络后自动同步，冲突会明确提示。

系统管理员可导出加密备份，也可预览后执行合并或覆盖恢复。离线副本不等于备份；请自行保存备份文件和备份密码。当前备份及恢复前快照各限制为 750 KiB。

备份包含手机号身份，不包含登录密码凭据、会话、设置链接或 init_key。恢复会使设备退出登录；覆盖恢复后，系统管理员先用自己的手机号和当前 init_key 设置新密码，再帮助家人设置密码。合并恢复保留现有账户密码，新导入成员需要设置密码。现有 v2 手机号备份继续支持，旧 Passkey 版本备份不支持直接恢复。

## 大字与日常使用

默认使用大字，可在登录页或“我的”切换标准、大字、特大；字号只保存在当前设备。手机底部提供首页、记录、用药、我的四个入口。首页优先显示今天用药和最近测量，点“切换”可查看家人资料；家庭管理位于“我的”。

记录测量时先确认页面上的姓名；高压和低压一起填写，也可只填写心率、血氧或体温。保存后先存入本机，联网后自动同步；未同步状态会在页面提示。

## 应用更新

发现并下载好新版本后，简护会显示“有新版本”，点击“立即更新”即可切换；也可以选择“稍后”，继续使用当前版本。在“我的 → 应用版本与更新”可以查看当前版本、构建标识并手动检查更新。

请先保存或取消正在填写的内容，等待保存、同步或备份处理完成。如有其他简护页面或窗口，请先保存并关闭它们，再更新当前页面。已经保存在本机的待同步记录和冲突会保留，更新不会主动退出登录。

从 v0.1.1 首次升级时，旧版本尚无更新入口：先保存内容，联网打开应用使其下载新版，再关闭该域名的所有浏览器页面和简护窗口后重新打开。必要时等待下载完成后再关闭、打开一次，无需清除网站数据或卸载应用。手机桌面图标的变化可能晚于页面更新，可通过应用内版本信息核对。
